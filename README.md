# Happy Herbivore

A dynamic, visually engaging web application featuring smooth slideshows, custom animations, and hidden secrets.

## Features

### 🎨 Visual & Interactions
- **Aesthetic Layout**: The dinosaur logo is prominently positioned for aesthetic balance.
- **Double-Buffered Slideshow**: Smooth crossfade transitions between food images.
- **Continuous Zoom**: Images have a subtle, linear zooming animation (`zoomInOut`).
- **Slogan Animation**: The "Healty in a Hurry" slogan floats gently and features a stylish outlined "copy" effect in green.
- **Dino Blink**: The logo character blinks naturally (single and double blink pattern) every 8 seconds.
- **Fullscreen Mode**: Toggle fullscreen with a button. Tap 5 times in the top-right corner to force exit.
- **Clean UI**: Text and element selection is disabled for a polished app-like feel.

### ☀️ Japanese Sunburst & Logo Animation
- **Sunburst Pattern**: After every **3** food slides, the background smoothly fades to a "Japanese Sun" effect.
- **Rotating Rays**: 12 orange and yellow rays rotate around a central orange sun.
- **Dynamic Logo**: When the sunburst appears, the logo **smoothly glides to the center** of the screen to align with the sun. It returns to its original position for standard slides.

### 🥚 Easter Egg
- **"67" Flash**: Every **67 seconds**, a black screen with a massive white "67" flashes for exactly one frame (the shortest possible duration). *Blink and you'll miss it!*

## Tech Stack
- **HTML5 / CSS3**: Custom animations, gradients, and layout.
- **JavaScript (Vanilla)**: Slideshow logic, DOM manipulation, input handling, and timing events.

## Setup
Just open `index.html` in a modern browser.
